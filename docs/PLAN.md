# د لوبې نقشه — Battle of Agents

## عمومي انځور

| برخه | پریکړه | ولې |
| --- | --- | --- |
| انجن | Unity 2022.3 LTS | اوږدمهاله ملاتړ، د game-ci بشپړ ملاتړ |
| ژبه | C# | ستاسو غوښتنه |
| ګرافیک | URP + سینمایي پوسټ‌پروسیسنګ | په ګرځنده کې لوړ کیفیت، خو ارزانه |
| شبکه | خپل سپک UDP+TCP سټیک | له بهرنیو پکیجونو پرته → کوچنی APK |
| خروجي | یو APK + زیپ (`7z -mx=9`) | لږ حجم |

## مرحلې

### ✅ مرحله ۱ — بنسټ او ټولې پاڼې
- د پروژې جوړښت، URP تنظیمات (د کوډ له لارې، نه YAML)
- `Theme.cs` + `UIKit.cs` — ټول UI په کوډ کې جوړېږي
- لس پاڼې: سپلش، اصلي مینو، کوټه جوړول، د وای‌فای لیست، لابي، ایجنټ ټاکل،
  د لوبې HUD، وقفه، پایلې، تنظیمات
- د هرې پاڼې سکرین‌شاټ په `docs/screenshots/` کې

### ✅ مرحله ۲ — د وای‌فای شبکه
- `LanDiscovery` — کوربه هر ثانیه UDP بیکن خپروي (پورټ 47777)
- `LobbyService` — TCP کنټرول چینل (پورټ 47778)، JSON پیغامونه
- ډله ټاکل، ready کول، چټ، د کوربه له خوا د لوبې پیل

### ⏳ مرحله ۳ — لوبغاړی او جګړه (روان کار)
- د مېدان جوړونکی (arena) + رڼا او سیوري
- د ټچ کنټرول: چپ لاس جوی‌سټیک، ښي لاس نښه/ډز
- وسله، ټپي کېدل، مړینه/بیا ژوندي کېدل، وړتیاوې (abilities)
- د کوربه واکمن سنیپ‌شاټ سنکرون (۲۰Hz UDP)، د پیرودونکي انټرپولیشن

### ⏳ مرحله ۴ — جوړول او خپرول
- GitHub Actions ورک‌فلو (چمتو دی)
- د حجم کمول: ARM64، IL2CPP، stripping، LZ4HC، ASTC
- زیپ کول په `7z -mx=9 -mfb=258 -mpass=15`
- د tag پر مهال ریلیز ته اپلوډ

### 🔜 مرحله ۵ — روزنه او روڼتیا
- د لوبې متن پښتو/انګلیسي (localization)
- د بوټ (AI) مخالفین د یوازې لوبې لپاره
- د غږ سیسټم او سینمایي کیمرې لنډې ویډیوګانې

## هغه څه چې ستاسو له خوا ته اړتیا لري

۱. **`UNITY_LICENSE` راز (secret)** — پرته له دې GitHub Actions نشي کولی Unity چلوي.
   د `.ulf` فایل منځپانګه په GitHub → Settings → Secrets کې کېږدئ.
۲. **د خپرولو کيسټور (اختیاري)** — که غواړئ APK د خپل کيلي سره لاسلیک شي.
